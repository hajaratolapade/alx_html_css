# Responsive Web Page

Welcome to the **Responsive Web Page** project! This project demonstrates a clean and interactive web design that adapts seamlessly to various screen sizes while maintaining a visually appealing layout. Below, you will find detailed information about the features, setup, and technologies used.

## 🌟 Features

- **Responsive Design**: 
  - Automatically switches to a mobile version when the screen width is 480px or less.
- **Interactive Links and Buttons**: 
  - Links change color to `#FF6565` on hover or active states.
  - Buttons have an `opacity: 0.9` effect on hover or active states.
- **Centered Content**: 
  - The main content is limited to a maximum width of 1000px and centered on the page for a neat, professional appearance.
